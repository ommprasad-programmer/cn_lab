
# Computer Networks Lab

A collection of Computer Networks Laboratory programs and practical implementations.

This repository contains programs designed to help students understand networking concepts through practical implementation.

## 📌 Repository

**GitHub:** [cn_lab](https://github.com/ommprasad-programmer/cn_lab)

## 🚀 Getting Started

### 1. Prerequisites

Make sure you have the following installed:

- Git
- GCC Compiler (for C programs)
- G++ Compiler (for C++ programs)
- Java JDK (for Java programs)

### 2. Clone the Repository

Open your terminal and execute:

```bash
git clone git@github.com:ommprasad-programmer/cn_lab.git
```

### 3. Navigate to the Project

```bash
cd cn_lab
```

### 4. Explore the Programs

```bash
ls
```

Navigate to the programs directory:

```bash
cd CN-Lab-Programs
```

List all available programs:

```bash
ls
```

## 💻 Compilation and Execution

### C Programs

Compile:

```bash
gcc program_name.c -o program_name
```

Execute:

```bash
./program_name
```

### C++ Programs

Compile:

```bash
g++ program_name.cpp -o program_name
```

Execute:

```bash
./program_name
```

### Java Programs

Compile:

```bash
javac ProgramName.java
```

Execute:

```bash
java ProgramName
```

## 🎯 Learning Objectives

- Understand fundamental networking concepts.
- Learn client-server architecture.
- Implement network communication.
- Understand networking protocols.
- Develop practical programming skills.

## ⚠️ Important Notes

- Use the appropriate compiler for each programming language.
- Check the program requirements before execution.
- Some client-server programs require two separate terminals.
- Start the server before running the client.
- Ensure the required ports are available.
